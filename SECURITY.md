# Security Policy

## Supported versions

No release is currently supported. Compatibility and support windows will be published before the first alpha.

## Reporting

Use GitHub private vulnerability reporting for this repository.

Do not include credentials, tokens, private company data, or exploitable details in public issues.

## Trust boundary

Mission Control will be treated as trusted self-hosted plugin code. It must request minimal capabilities and must not bypass Paperclip approval, budget, checkout, authorization, or audit controls.
